# Roadmap

## v0.2 — More core lessons
- Lesson 11: logistic regression — from regression to classification
  probabilities, with from-scratch code
- Lesson 12: evaluating classifiers beyond accuracy (precision, recall,
  confusion matrix) with worked examples
- More quiz questions and short exercises per lesson

## v0.3 — Better learning experience
- A gentle "math you actually need" appendix (vectors, means, basic
  probability) in Vietnamese
- Worked case studies that chain algorithms (e.g. cluster first, then
  classify), synthetic data only
- Optional English translations of the lessons

## v0.4 — Ecosystem
- Printable/PDF edition of the curriculum for classrooms and clubs
- Exercise notebooks in plain-Python script form (still zero-dependency)
- Community-contributed examples from Vietnamese classrooms

## Ongoing maintainer commitments
- Weekly issue triage and PR review
- Security-first handling of reports (see SECURITY.md)
- A tagged release at least once per quarter while the project is active
